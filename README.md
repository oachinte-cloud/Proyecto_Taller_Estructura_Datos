## Descripción del Proyecto

Este repositorio contiene la solución completa del taller de Estructuras de Datos Lineales, enfocado en la manipulación eficiente de arreglos unidimensionales, matrices bidimensionales y ArrayLists en Java.

El objetivo principal es aplicar los conceptos fundamentales de memoria, estructuras de datos contiguas y dinámicas, análisis de complejidad (Notación Big-O) y principios de código limpio. Cada ejercicio está modularizado mediante métodos con responsabilidades únicas y ejecutables desde consola.
